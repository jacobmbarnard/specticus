# Use Cases

*Use cases describe interactions between actors and the system to achieve goals.*

## UC-001: User Authentication

**Description**

A registered user authenticates to gain access to the application.

**Primary Actor**

Registered User

**Preconditions**

- User has valid corporate credentials.

**Main Flow**

1. User navigates to login page.
2. User enters email and password.
3. System validates credentials.
4. System redirects user to dashboard.

**Success End-Condition**

User is authenticated and sees the dashboard.

**Failure End-Condition**

User sees an error message and remains on login page.
